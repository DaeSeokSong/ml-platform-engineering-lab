# 자료 출처와 범위

『머신러닝 플랫폼 엔지니어링』과 스터디의 CH4·CH5 안내를 참고해 직접 실습한 작업본을 정리했습니다.

- [스터디 CH4·CH5 안내](https://app.notion.com/p/gasidaseo/CH4-CH5-40350aec5edf80ddab8bdc044799ac30)
- [스터디 환경 설치 부록](https://app.notion.com/p/gasidaseo/A-kubeflw-mlflow-40150aec5edf8000b9a7fa2317d87675)

링크는 원문 출처이며 접근 권한이 필요할 수 있습니다. 자료 전문·강의 녹화·책 PDF·원본 ZIP을 이 저장소에 재배포하지 않습니다. 예제에서 파생한 파일의 출처를 표시하고 저장소 전체에 임의의 재라이선스를 선언하지 않습니다.

우리 실습은 기존 kind 클러스터, SeaweedFS, 독립 SDK 환경을 사용한 변형입니다. 스터디의 전체 Kubeflow Community Distribution 설치를 그대로 재현했다고 주장하지 않습니다.
