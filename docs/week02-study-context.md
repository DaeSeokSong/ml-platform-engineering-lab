# 2주차 공개 진행 기록

공통 방식은 [하네스](study-harness.md)를 따릅니다. 개념 문답 후 기능별 코드 청크로 실습하며, 2주차의 별도 토이 프로젝트는 제외합니다.

- 사용자 실행 확인: 모델 비교·MLflow 모델 버전·Feast/Redis/S3·KFP 통합 DAG SUCCEEDED.
- 에이전트 실행 확인: 독립 데이터·모델·피처 재현, Garage·VersityGW 비교, 실제 S3 예측 CSV, 인터랙티브 설명 조작 검사.
- 남은 확인: 빈 PC에서의 전체 설치, 공개 게시 여부.
- 공개 글 상단에는 해당 버전의 하네스·재현 프롬프트를 두고 바로 다음에 GitHub 저장소 링크를 넣습니다.
- 이 기록은 비공개 대화 전문·인증정보·개인 ID를 제외한 공개용 요약입니다.

- 2026-10-29 티스토리 글쓰기: 제목·본문 입력 후 미리보기에서 펼치기 7개와 이미지 2장을 검증했습니다. 발행은 하지 않았습니다.
