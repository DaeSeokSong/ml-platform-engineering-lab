# 로컬 보관 구조

```text
study/mlops/
├── mlops-reference/                기존 자료·원본·비공개 학습 기록
└── ml-platform-engineering-lab/    GitHub에 공개할 실습 작업본
```

공개 저장소는 mlops-reference 폴더 없이도 문서가 읽히도록 구성합니다. 입력 데이터·서비스 준비는 각 README의 조건을 확인합니다. 실제 실행 중인 WSL의 ~/ml-platform-lab과 Docker 볼륨은 이 폴더 정리로 이동하지 않습니다.

## 2026-10-29 추가 실행

Garage 2.5.0·VersityGW 1.8.0을 전용 컨테이너로 구성하고 3개 저장소×3개 파일을 검사했습니다. 공개 UCI 데이터에서 독립 작업 폴더의 모델·Feast 흐름도 재현했습니다. 실제 저장 결과 CSV 3행 확인과 인터랙티브·블로그 로컬 미리보기 검사를 통과했습니다. 에이전트가 실행한 검사이며 기존 사용자의 기본 실습과 구분합니다.

옛 안내 폴더는 현재 세션의 프로세스 잠금 때문에 삭제되지 않았습니다. 안내 파일은 정리됐으며 내용 없는 옛 폴더만 남아 있습니다. 실제 참고 자료·공개 작업본·WSL 데이터는 보존했습니다.
